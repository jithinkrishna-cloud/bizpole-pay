Developers

Build your own payment flow

One REST call creates an order. We handle hashing, provider callbacks, verification and webhooks.

  1. Create an orderYour server sends the amount and customer details.
  2. Redirect to checkoutThe customer pays on the hosted page.
  3. We verify the paymentStatus is confirmed with the provider before it's marked paid.
  4. Get a signed webhookUpdate your order. Failed deliveries are retried and logged.
Get your test keys 
// server-side, Node.js
const order = await fetch("https://api.bizpolepay.example/v1/orders", {
  method: "POST",
  headers: { Authorization: `Bearer ${BIZPOLEPAY_TEST_KEY}` },
  body: JSON.stringify({
    amount: 49900,          // in paise
    receipt: "INV-1042",
    customer: { name: "Asha", email: "asha@example.in" },
    return_url: "https://shop.example.in/thanks"
  })
}).then(r => r.json());

res.redirect(order.checkout_url);

// webhook: payment.success
// { order_id, txn_id, amount, mode, settled_at }
