Developers

Create an order, redirect, done

One REST call creates an order. We handle hashing, payment-provider callbacks, verification and webhooks.

  • Separate test and live keys
  • Signed webhooks with retries and a delivery log
  • Status confirmed with the payment provider before a payment is marked paid
  • Idempotent refunds and payouts
// server-side · Node
const order = await fetch("https://api.bizpolepay.example/v1/orders", {
  method: "POST",
  headers: { Authorization: `Bearer ${BIZPOLEPAY_TEST_KEY}` },
  body: JSON.stringify({
    amount: 49900,          // paise
    receipt: "INV-1042",
    customer: { name: "Asha", email: "asha@example.in" },
    return_url: "https://shop.example.in/thanks"
  })
}).then(r => r.json());

res.redirect(order.checkout_url);

// webhook → payment.success { order_id, txn_id, amount, mode }
